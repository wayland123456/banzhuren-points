# 班主任工作台 · 高三（8）班

一个**单文件、纯前端、离线可用**的班主任日常管理工具。双击 HTML 就能跑，不需要安装、不需要服务器、不需要登录。数据保存在浏览器本地（`localStorage`），换设备不会自动同步。

> 在线使用：https://wayland123456.github.io/banzhuren-points/

---

## 功能模块（15 个）

| 模块 | 说明 |
| --- | --- |
| 仪表盘 | 当日待办、班级概览、关键数据一屏看完 |
| 日程安排 | 教学与班级事务时间线 |
| 我的课表 | 动态网格课表，支持拍照识别导入 |
| 学生管理 | 名单、分组、基础信息维护 |
| 成绩分析 | 成绩录入与进退步统计 |
| 违纪统计 | 违纪记录与累计扣分 |
| 作业管理 | 作业布置与上交情况登记 |
| 请假管理 | 请假登记与销假追踪 |
| 工作留痕 | 日常班级工作记录留档 |
| 谈话记录 | 学生谈心谈话档案 |
| 排座位 | 座位编排与调整 |
| 家校沟通 | 家长联系记录 |
| 班级活动 | 活动组织与留存 |
| 待办备忘 | 零散事项随手记 |
| **积分管理** | 小组/个人积分加减、排行、明细记录 |

## 使用方式

**方式一：在线打开（推荐）**
直接访问上面的 GitHub Pages 地址，手机、电脑、平板都能用，可加到主屏幕当 App 使用。

**方式二：本地打开**
下载 `index.html`，双击用浏览器打开即可，完全离线。

**数据说明**
- 所有数据存在当前浏览器的 `localStorage`（键名 `cm8_db`），清缓存/换浏览器会丢失。
- 重要数据请定期用工具内的导出功能备份。

## 技术栈

- 单文件 HTML + CSS + 原生 JavaScript，零依赖、零构建
- 图标与布局手写，无第三方 UI 框架
- 课表拍照识别可选接入 Supabase Edge Function（`ai-proxy`）做 OCR，不联网时其余功能不受影响
